Traveller reading — Anthropic API

Reading a traveller image sends the pages to Anthropic's API using your own key. It needs internet, so it will not work on a shop-floor machine that is offline. Everything else in this app runs with no network at all.

How the key is handled. It is stored in this browser's local storage and sent only to api.anthropic.com. It is never written into a saved .json, never into an exported .xlsx, and never leaves this machine anywhere else. It is stored in clear text, as browser storage always is — on a shared or kiosk machine, use Forget key when you finish. Use a key scoped to this purpose rather than an organisation-wide one, and rotate it if the machine changes hands.

Project-wide classifications: slug squareness gage is variable (cap 4); go/no-go Deltronic pins on bores under .0005″ total tolerance are attribute (cap 5); all Mitsubishi grind inspection is 100%, so run-out is Det 4, not 5.

The other five conventions

#1 — Detection is the single strongest control Redundant controls do not reduce Det. Controls checking different characteristics get their own lines. Anything in column L or O documents redundancy for audit and earns no rating credit.
#2 — Severity cannot be reduced by inspection Only a design change, process change, or redefined failure-effect scope moves Sev. 100% inspection changes whether the failure escapes, not the consequence when it does.
#4 — Probing earns Occurrence credit only with auto-offset No CAMCO machine qualifies today. Hardinge Quest lathes have no probes at all; the Haas UMC has the kit installed but does not use the auto-offset option. Probing on either is Detection only.
#6 — Residual risk acceptance When RPN cannot go lower, document the floor and why, that prevention and detection are at AIAG limits or process capability, and QE plus customer SQE sign-off with a date. Stuck-high RPN with no rationale is an audit finding.

Current-state process facts — Section 3

Facts about how CAMCO operates today, not aspirations. A row crediting a control that does not exist is the most damaging error this project produces, because it survives review and misrepresents risk to the customer.

Certs are not compared to bar tags at receipt CX718-1 is authored at Rev-00 but not released; planned operational start Q3 2026. Cert-vs-tag-dependent rows rate Det 10 until the gate is released and operating.
CNC programs are not locked down at any controller Hardinge Quest, Mitsubishi grinder, and Haas UMC all allow full operator edit access, with no change-control gate and no checksum or diff at setup. Every PFMEA covering a CNC machining op carries the program-edit row until lockdown operates.
The Mitsubishi grinder dresses the wheel before every part Real machine-level prevention worth roughly one Occ step — but it is operator practice, not in a controlled procedure. Taking the credit requires a formalization action, and the prevention text must disclose the gap. One procedure retires it for every grind op on the machine.
Hardinge specifics Main spindle TIR ≤ .0001, so main spindle runout is not a valid cause on turning ops — use tool wear, work-hardening, programming offset, or bar-feed inconsistency. Live-tool spindle runout is valid on cross-hole ops. No climb milling and no helical toolpaths; straight drilling, axial plunge, and circular interpolation only.
Military application by default Jungle, desert, maritime environments; thermal and vibration cycling on a reusable unit. Write "military hardware," never "flight hardware" or "avionics," and never name a program. Flag ferromagnetic substitution near IMU, magnetometer, or gimbal sensors.
